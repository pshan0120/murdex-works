# 도플로이드(Doploid) 서사 작성 원칙 (MANDATORY RULES)

이 문서는 '도플로이드' 프로젝트의 서사 대본을 작성할 때 반드시 지켜야 할 철칙을 정의한다. 모든 서사 작업 시 이 규칙을 최우선으로 참조한다.

---

## 1. 퀴즈 정답 및 키워드 노출 금지
*   **정답 언급 금지:** 각 서사 단계에서 플레이어가 맞힌 **'정답 단어'**를 대사에서 직접 언급하는 것을 절대 금지한다.
    *   (예: 정답이 '신사'인 경우, 대사에 "신사답게 행동하던 기억이 나"라고 쓰지 않는다.)
*   **키워드 언급 금지:** 정답을 역순으로 읽어 도출되는 **'키워드'**를 대사에서 직접 언급하는 것을 절대 금지한다.
    *   (예: 키워드가 '사신'인 경우, 대사에 "사신이 나를 데리러 온 것 같아"라고 쓰지 않는다.)
*   **키워드 연상 힌트 금지:** 키워드를 추측할 수 있게 만드는 **구체적인 명사나 배경 지식**의 노출을 금지한다.
    *   (예: 키워드가 '사탄'인 경우, 지옥이나 악마를 직접 묘사하지 않고 '서늘한 웃음소리' 등 추상적 감각으로만 표현한다.)

## 2. 캐릭터 톤앤매너 (Tone & Manner)
### 🛡️ 레바 (Leba / A)
*   **세계관:** 중세 판타지, 신앙 중심, 봉건 사회.
*   **어투:** 고전적인 문어체, 사극풍 말투.
*   **금기:** 현대적 과학 용어, IT 용어, 현대 사회의 시스템(경찰, 대학교, 적금 등)을 이해하지 못하며 이를 '사술'이나 '마법'으로 해석한다.

### 🧪 니악 (Niac / C)
*   **세계관:** 현대 사회, 이과 대학생, 공학도.
*   **어투:** 현대적인 구어체, 논리적이고 상식적인 말투.
*   **금기:** 본인이 안드로이드임을 인지하는 기계적 용어(**포맷, 데이터, 시스템, 노이즈, 폐기, 입력**)를 사용하지 않는다. 모든 상황을 '꿈', '환각', '정신 착란'으로 해석하며 본인은 인간이라고 굳게 믿는다.

## 3. 시스템 설정의 내러티브화
*   **입력 패널 설정:**
    *   **서사 1단계:** 입력창이 **'2글자'**만 입력 가능한 기괴한 형태임을 니악이 언급한다.
    *   **서사 11단계:** 10개의 퀴즈가 끝난 후, 패널이 빛을 내며 **'영문 5글자'** 입력 방식으로 물리적으로 변하는 연출을 대사에 포함한다.

## 4. 에피소드 작성 가이드
*   퀴즈 정답은 오직 **'기억을 불러일으키는 트리거'**로만 작동한다.
*   대사는 "이번 문제를 풀고 나니..."로 시작하여, 해당 단어가 함축하는 **분위기, 색채, 소리, 온도, 정서** 위주로 묘사한다.
*   플레이어가 정답을 맞힌 후 그 단어를 뒤집었을 때 느껴지는 반전의 재미를 대사가 미리 가로채지 않도록 주의한다.

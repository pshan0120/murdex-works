# 효과음

여러 작품에서 다시 쓸 효과음을 모아 두는 곳이다. 여기에 둔 파일은 머덱스 플랫폼의 "효과음 라이브러리"(관리자가 등록하고 작가가 대본 줄에서 골라 쓰는 기능)에도 등록해 쓴다.

## 규칙
- 직접 만든 소리만 둔다(코드로 합성하거나 직접 녹음). 외부 음원은 이용 조건이 작품마다 달라서 이 폴더에 섞지 않는다.
- 폴더는 분류(`phone/` 전화, 이후 `door/` 문, `step/` 발소리 등), 파일명은 "분류_내용.wav"로 쓴다.
- 만드는 스크립트는 같은 폴더에 두고 파일은 언제든 다시 만들 수 있게 한다.

## 현재 목록
| 파일 | 설명 | 길이 | 쓰인 곳 |
|---|---|---|---|
| `phone/전화_발신_연결음.wav` | 휴대폰 발신. 터치음, 연결음(440Hz+480Hz) 2번, 상대가 받는 딸깍 | 약 7초 | 게화 추리 단계(4, 6, 8, 10단계) 통화 시작 지시문 |

## 업로드와 연결
대본 줄에는 `audio_url`(Cloudinary 주소)만 들어간다. 업로드는 `/api/storage/upload/audio`, 연결은 대본 줄 테이블의 `audio_url`이다. 작품마다 같은 파일을 다시 올려도 되고, 이미 올린 주소를 그대로 쓸 수도 있다. 올린 주소는 `등록_효과음.json`에 기록한다. 게화의 통화 효과음은 `murdex-api/scripts/sync_gehwa_deduction_calls.py --apply`가 올리고(개발 서버가 꺼져 있어도 저장소 서비스를 직접 사용하므로 업로드 기록 테이블에는 남지 않는다) 4개 추리 단계의 첫 지시문에 연결한다.

## 플랫폼 라이브러리 (2026-10-16 구현)
- `sound_effect` 테이블(분류, 이름, 설명, 주소, 길이, 출처)에 두고, 대본 줄 편집 화면의 오디오 항목에서 "효과음 라이브러리에서 고르기"로 고른다. 관리자는 `/admin/sound-effects`에서 등록, 수정, 삭제한다.
- 줄에는 선택한 효과음의 주소만 복사되므로 라이브러리를 고쳐도 이미 만든 작품은 바뀌지 않는다.
- 이 폴더의 파일을 라이브러리에 올릴 때는 `murdex-api/scripts/register_sound_effects.py`의 `META`에 분류, 이름, 설명을 추가하고 `--apply`로 돌리거나, 관리자 화면에서 직접 올린다.
- 분류는 자주 쓰이는 전화(발신, 수신 벨, 연결, 끊김)부터 시작한다.

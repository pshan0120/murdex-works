# format-txt-html 스킬 지침

이 스킬은 텍스트 파일 내의 HTML 블록 포맷팅이 손상되었거나 일관되지 않을 때, HTML 영역의 들여쓰기를 2칸(spaces) 기준으로 자동 교정하는 스킬입니다. 순수 텍스트 영역은 건드리지 않습니다.

## 언제 이 스킬을 사용해야 하는가?
- 사용자가 "HTML 포맷팅이 깨졌다"거나 "HTML 들여쓰기를 맞춰달라"고 요청할 때.
- `단서.txt`, `역할_*.txt` 등의 파일을 수정한 후, 치환 과정에서 HTML 영역의 들여쓰기가 망가진 것을 스스로 감지했을 때.

## 작동 원리
- 이 스킬은 동봉된 `scripts/format_html.py` 스크립트를 사용하여 파일을 포맷팅합니다.
- 스크립트는 줄의 시작이 `<`로 시작하는 영역부터 짝이 맞는 닫는 태그(예: `</div>`, `</ul>` 등)가 나올 때까지를 HTML 블록으로 인식합니다.
- 추출된 HTML 블록을 BeautifulSoup를 이용해 파싱하고 다시 2칸 들여쓰기로 이쁘게 출력하여 원래 파일에 덮어씁니다.

## 사용 방법
1. 포맷팅하고자 하는 파일의 절대 경로를 파악합니다.
2. 터미널(`run_command` 도구)을 통해 아래와 같이 파이썬 스크립트를 실행합니다.

```bash
python "c:\dev\KLIEN\murdex\works\.agents\skills\format-txt-html\scripts\format_html.py" "포맷팅할_파일_절대_경로.txt"
```

3. 실행 결과 출력(에러 또는 성공 메시지)을 확인합니다.
4. 파일 내용이 정상적으로 포맷팅되었는지 `view_file` 등으로 검증합니다.

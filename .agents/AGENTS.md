# 엔딩 작성 규칙
앞으로 모든 캐릭터의 엔딩을 개선하거나 새로 작성할 때 반드시 다음 규칙을 준수합니다.

1. **한자어 사용 금지**: 괄호 안에 한자를 병기하거나(예: 사지(死地)), 불필요하게 어려운 한자어 사용을 피하고 자연스러운 한국어를 사용합니다.
2. **AI가 쓴 티가 나면 안 됨**: '결국', '그렇게', '마침내' 등 AI 특유의 진부하고 기계적인 수식어와 뻔한 감정 묘사를 지양하고, 담백하면서도 문학적인 표현을 사용합니다.
3. **배경이야기 선독해 필수**: 캐릭터의 엔딩을 수정하기 전, 반드시 해당 역할의 배경이야기 파일(예: `역할_X_이름.txt`)을 먼저 읽어 캐릭터의 진의, 과거, 성격을 완벽히 파악합니다.
4. **여운 극대화**: 플레이어가 엔딩을 읽었을 때 캐릭터의 비극성이나 결말에 대해 깊은 여운을 느낄 수 있도록 몰입감 있게 작성합니다.
5. **공통 엔딩과의 자연스러운 연결**:
   - 1) **처형 엔딩(개인)**: 본인이 처형 대상으로 지목된 경우, 마신과의 전투가 벌어지기 전에 죽음을 맞이하므로, 마신의 부활이나 마신과의 전투 상황을 전혀 알지 못하는 상태로 묘사해야 합니다.
   - 2) **마신 전투 이후 엔딩(승리/패배)**: 공통 엔딩에서 벌어진 마신과의 전투 결과(승리 또는 패배)와 매끄럽게 이어지는 느낌을 주어야 하며, 전투 직후의 상황과 캐릭터의 심리가 잘 연결되어야 합니다.
6. **2인칭 시점 서술(개별 엔딩)**: 개별 엔딩은 해당 역할을 담당한 플레이어가 직접 읽는 텍스트이므로, 주인공 캐릭터를 3인칭(이름, 그, 그녀 등)이 아닌 2인칭('당신')으로 서술하여 몰입감을 높입니다.

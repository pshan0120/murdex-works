### 1-2. AI가 만든 일기 문장이 사람이 읽기에 어색함
- 테스터 원문: "주인 마음이 뒤숭숭한 것 같았다 → 그래서 나에게 담요를 새로 깔아주었다, 이 부분이 약간 어색한 것 같습니다"
- 해당 AI 생성문: "주인이 바쁜 날이 많았다. 마음이 뒤숭숭한 것 같았다. 그래서 나에게 담요를 새로 깔아주었다. 그 위에 웅크리고 잠들었다. …주인이 내 이야기를 하면서 나를 바라보았다. 나는 조용히 듣고 있었다."
- 원인 분석:
  - 원본 단서(clue "담요 자리", 2년)는 "요즘 회사 일이 유난히 바빠 마음이 뒤숭숭했다. **그 마음을 달래려 괜히 집안일을 붙잡다가**, 낮잠 자리에 두꺼운 담요를 새로 깔아주었다." AI가 강아지 시점으로 압축하면서 가운데 연결고리(마음을 달래려 집안일을 붙잡음)를 빼고 "그래서"로 바로 이어붙여, "뒤숭숭해서 담요를 깔아줬다"는 억지 인과가 생김.
  - 바로 뒤 문장은 다른 단서("마음에 두었던 사람과 잘 되지 않았다. 그 이야기를 한참 늘어놓았다")에서 온 내용인데, 연결 없이 붙어 있고 "내 이야기를 하면서"로 뜻까지 바뀜(원본은 주인이 자기 이야기를 강아지에게 털어놓는 장면).
  - 전반적으로 짧은 단문이 "~했다."로만 반복되어 리듬이 기계적임.
- 추가 원인(코드 확인, 2026-09-25):
  - 일기 시스템 프롬프트(`_DIARY_ENTRY_SYSTEM_PROMPT_TEMPLATE`) 규칙 1이 "-다로 끝나는 짧은 문장을 이어 붙입니다(예: 오늘은 공을 물어왔다. 주인이 웃었다. 좋았다.)"로 단문 나열을 직접 지시함. 기계적인 리듬의 직접 원인.
  - 규칙 8이 "주인은 몰랐던 진짜 이유를 새로 지어내서 보태라"고 요구함. 모델이 이유를 만들어 붙이면서 "그래서"로 억지 인과를 거는 경향이 여기서 나옴.
  - 단서 여러 개를 `" ".join(memory_texts)`로 공백 하나로 이어 한 덩어리로 넘김. 모델 입장에서는 별개 사건의 경계가 안 보여, 서로 다른 날의 일을 한 흐름으로 이어 쓰게 됨.
- ✅ 조치 완료(2026-09-25, `murdex-api/domain/room/controllers/encore_router.py`, 배포 필요):
  - 가드 수정: `_ENCORE_REWIND_STORY_ID` 추가, 리와인드 방도 일기장/편지 API 사용 가능하게 함.
  - 리와인드 전용 프롬프트 `_REWIND_DIARY_ENTRY_SYSTEM_PROMPT_TEMPLATE` 신설(앙코르 원본 프롬프트는 그대로). 규칙 1(문장 길이·어미 섞기, "~다" 통일), 규칙 3("~것 같았다" 짐작 금지), 규칙 8(주인 사정→주인 행동 인과 연결 금지), 규칙 11(한 문단 3~6문장, 줄바꿈 금지), 규칙 13(질문+답을 받아 종류에 맞게 녹이기, 견주는 표현·사건에 끼워 넣기 금지), 규칙 14(번호별 사건 섞지 않기, 행동 주체 유지) 반영.
  - 입력 구조: 리와인드는 단서를 번호 목록으로, 질문은 `[이번 주 주인이 답한 질문] 질문/답`으로 넘김.
  - 모델: 리와인드 일기는 gpt-4o 사용(편지와 동일). gpt-4o-mini로는 같은 프롬프트에서도 "그래서" 억지 인과가 4번 중 3번, 행동 주체 뒤바뀜이 1번 나와 규칙이 지켜지지 않았음. 비용은 한 판(일기 16편) 기준 대략 0.1~0.2달러 수준으로 늘어남.
  - 자동 재생성: "그래서", "그런지", "좋지만", "가/이 아니라"가 나오면 기존 규칙 위반 검사처럼 즉시 재생성(최대 3회, 마지막 일기는 제외).
- 검증: 테스터가 지적한 두 단서("담요 자리" + 속마음 털어놓기)와 관찰형 질문(좋아하는 자리: 소파)을 같은 입력으로 넣고 실제 재시도 루프대로 5번 생성 → 5번 모두 통과(4번은 첫 시도). 억지 인과 없음, "다른 날에는/며칠 뒤"로 사건 구분, "주인이 내게 이야기를 털어놓았다"로 주체 유지.
  > 예시 결과: 주인이 집안일을 하다가 내 자리에 두꺼운 담요를 깔아줬다. 그 위에 몸을 웅크리니 푹신한 감촉이 온몸을 감쌌다. 잠이 솔솔 와서 그대로 잠들었다. 다른 날에는 주인이 내게 이야기를 했다. 목소리에서 무거운 기운이 느껴졌지만 나는 그저 옆에 앉아 있었다. 주인의 숨결이 조금 가라앉을 때까지 가만히 있었다.
- 남은 약점: 가끔 "주인의 기분이 조금 나아졌으면 좋겠다"처럼 바람을 말하는 문장이나 "~말이다" 같은 어색한 끝맺음이 섞임. 실제 플레이 결과를 더 보고 판단.
- 처음 검토했던 해결 방향: `murdex-api/domain/room/controllers/encore_router.py`의 일기 생성 프롬프트 보강. 예) 원인·결과를 새로 만들어 잇지 말 것("그래서", "그러자" 남용 금지), 서로 다른 단서는 문단이나 시간 표지로 구분할 것, 원본 행위의 주체를 바꾸지 말 것, 문장 길이를 섞을 것. 수정 후 같은 입력으로 여러 번 생성해 비교 필요.

# 백양둔의 밤 단서 초안 (v0.1)

작성 2026-11-10. 기획안 v0.3의 6장을 바탕으로 쓴 초안이다. clue_id, variant_id, HTML, 이미지 프롬프트는 DB 등록 때 붙인다.

## 작성 원칙

- 단서에는 보고 들은 사실만 쓴다. 누구로 보인다는 추정, 동기, 심리는 쓰지 않는다.
- 수식은 붙이지 않는다.
- 물증과 관찰은 "~입니다"로, 개인 기억은 1인칭 "~했다"로 쓴다.
- 기억 카드는 한 장에 한 장면만 담는다. 시간이 다른 장면을 한 장에 이어 붙이지 않는다.
- 각 항목의 "사슬"은 기획안 6.5의 A~D, "누명"은 6.4의 누명 풀기에 쓰이는 단서라는 뜻이다.

## 표기

- 획득: **조사**(장소나 인물을 조사해 얻음, AP 소모) / **시작**(역할 시작 때 가짐) / **도착**(해당 단계 시작 때 자동 획득) / **조합**(단서 의존으로 열림)
- 교환: GIFT·SHARE 가능 여부

## 1. 장소 조사 단서 (단계 1부터)

### 1.1 마방

**L01 한태수의 시신**
- 유형: 관찰 / 획득: 조사 / 교환: 불가 / 사슬: A, 누명(칼자국)
- 내용:
  가슴에 찔린 상처가 하나 있습니다. 왼쪽 광대와 입가에 멍이 들어 있습니다. 저고리 앞섶이 풀려 있고 안주머니가 뒤집혀 있습니다.
- 의도: 치명상은 칼이고 주먹은 따로라는 점. 품을 뒤진 사람이 있다는 점.

**L02 한태수의 발과 허리**
- 유형: 관찰 / 획득: 조사 / 교환: 불가 / 사슬: 누명(수란, 칼자국)
- 내용:
  장화 두 짝과 버선이 벗겨져 짚 위에 흩어져 있습니다. 허리띠에는 주머니 끈을 매던 고리만 남아 있습니다.
- 의도: 시신을 뒤진 사람이 둘 이상이라는 것과 무언가 없어졌다는 것. 누가 무엇을 가져갔는지는 P08(칼자국), P11·P12(수란)와 합쳐야 나온다.

**L03 여물통**
- 유형: 물증 / 획득: 조사 / 교환: 가능 / 사슬: A
- 내용:
  짚 속에 칼 한 자루가 묻혀 있습니다. 칼날에 피가 말라 붙어 있습니다. 손잡이에 금화루 낙인이 찍혀 있습니다.
- 의도: 흉기가 금화루 주방 것. 류춘화가 바로 의심받는 출발점.

### 1.2 금화루 주방

**L04 아궁이**
- 유형: 물증 / 획득: 조사 / 교환: 가능 / 사슬: A
- 내용:
  재 속에 타다 만 종이 조각이 있습니다. "…시 반, 마방에서"라는 글씨가 남아 있습니다.
- 의도: P01(옥이의 쪽지 심부름)과 합쳐야 누가 받은 쪽지인지 이어진다.

**L05 칼꽂이**
- 유형: 관찰 / 획득: 조사 / 교환: 불가 / 사슬: A
- 내용:
  칼꽂이 다섯 칸 중 한 칸이 비어 있습니다.
- 의도: L03과 맞물리는 보강. 단독으로는 아무것도 가리키지 않는다.

### 1.3 마작방

**L06 마작방 장부**
- 유형: 기록 / 획득: 조사 / 교환: 가능 / 사슬: 누명(진덕생)
- 내용:
  오늘 오후 판. 진 사장 외 세 사람. 두 시 시작, 다섯 시 삼십오 분 끝.
- 의도: 진덕생이 5시 30분에 마작방에 있었음.

### 1.4 우물가

**L07 빨래돌**
- 유형: 관찰 / 획득: 조사 / 교환: 불가 / 사슬: A
- 내용:
  두레박 옆 빨래돌 틈에 붉은 물기가 고여 있습니다.
- 의도: P07(진덕생 목격, 우물 쪽으로 감)과 이어지는 보강.

### 1.5 2층 3호실

**L08 3호실**
- 유형: 관찰 / 획득: 조사 / 교환: 불가 / 사슬: 누명(칼자국, 오카다)
- 내용:
  빈 고량주 병 두 개와 잔 두 개가 상 위에 있습니다. 방 구석에 "동아척식" 글자가 박힌 가죽 가방이 있습니다.
- 의도: 3호실이 오카다의 방이라는 것. 술 시중 기록(P15)과 합쳐야 알리바이가 된다.

- 내용:

### 서일몽

**P05 상영실**
- 교환: 가능 / 사슬: A
- 내용:

**P06 세 시의 형**
- 교환: 가능 / 사슬: 없음
- 내용:
  세 시쯤 형이 상영실에 찾아와 "오늘 밤 옛 빚을 정리한다"고 말했다.

### 진덕생

**P07 다섯 시 사십 분의 마방**
- 교환: 가능 / 사슬: A
- 내용:
  다섯 시 사십 분쯤 마방 앞에 갔다. 문이 열리고 흰 두루마기에 갓을 쓴 사람이 나와 우물 쪽으로 걸어갔다. 나는 마방에 들어가지 않았다.
- 의도: 누구인지 쓰지 않는다. 마방에 간 이유는 역할지 비밀에만 있다.

### 칼자국

**P08 여섯 시 십 분의 마방**

### 오카다

  날짜와 숫자가 줄마다 적힌 쌀 장부 한 장입니다. 숫자는 셋씩, 넷씩 끊겨 있습니다.

**I02 찬송가 책**
- 내용:
  낡은 찬송가 책입니다. 뒤표지 안쪽에 가나다 한 줄과 숫자 한 줄이 위아래로 적힌 종이가 붙어 있습니다.

**I03 해독한 명부** (I01과 I02를 한 사람이 모두 가지면 열림)
- 내용:
  영사관 연락원 명단
  - 학: 1920년 10월 토벌대 길 안내. 1922년 회령에서 간도로 거처를 옮김
  - 까마귀: 봉천 출신. 1929년 겨울부터 남의 이름을 씀
  - 제비: 용정 거주. 1926년부터
  - 두더지: 훈춘 거주. 1928년부터
- 의도: 넷 중 둘만 이 방 안에 있다. 이름은 하나도 나오지 않는다.

**I04 도장 주머니**
- 내용:
  가죽 주머니에 상아 도장 하나가 들어 있습니다. 도장에는 "한태수" 세 글자가 새겨져 있습니다.

**I05 차용증**
- 내용:
  한태수가 진덕생에게 오백 원을 빌리고 개척단 논 서른 마지기를 담보로 잡힌다. 날짜는 사흘 전 밤. "마작방에서 증인 앞에 날인". 한태수의 도장이 찍혀 있다.

**I06 숙박 장부**
- 내용:
  사흘 전 밤 기록. 2층 1호실, 한태수, 밤 아홉 시 입실, 혼자. 이튿날 아침 일곱 시 퇴실.
  같은 장에 3호실, 오카다 시게루, 열흘째 투숙 중.
- 의도: 사슬 D와 3호실 투숙객 확인을 한 장에 담았다. 류춘화가 장부를 팔면 칼자국·오카다의 알리바이 조합 하나도 함께 약해진다(L08로 대신할 수 있음).

**I07 강철수의 편지**
- 내용:
  태수, 태호 보게. 우리를 판 사람은 회령에서 약방을 하던 사람일세. 길을 앞장선 것을 내 눈으로 봤네. 나는 여기까지인 듯하니 두만이를 부탁하네. 1920년 11월, 철수.
- 의도: "태호"는 서일몽의 본명. 이 편지를 보이면 서일몽의 정체도 함께 드러날 위험이 있다.

**I08 약봉지**
- 내용:
  흰 가루가 든 약봉지입니다. 겉에 일본어로 "한 번에 반 숟가락"이라고 적혀 있습니다.

**I09 말린 약초 묶음**
- 내용:
  붉은 끈으로 묶은 마른 풀뿌리 한 묶음입니다.
- 의도: 해독 효과는 수란의 역할지에만 적는다. 단서 문장에서는 효능을 말하지 않는다.

## 6. 사슬 검증

| 사슬 | 필요한 단서 | 한 사람이 처음부터 다 가진 경우 | 단독으로 결론이 나는 단서 |
|---|---|---|---|
| A | P01 + L04 → P13 → P07 + A06 + P05/P10 (+ B01, L07) | 없음 | 없음. P07은 차림만, A06은 두 사람, P05는 알리바이만 |
| B | I03 + I07 + A01 | 없음(I03은 옥이와 두만이 조각을 합쳐야 열림) | 없음. I03은 가명, I07은 직업과 고향, A01은 이력만 |
| C | I03 + A02 | 없음 | 없음 |
| D | I05 + I06 | 없음 | 없음 |

- 사슬 A에서 진범이 단서를 숨겨도(B01) 결론이 나는지: P07 + A06 + P05/P10만으로 성립함
- 사슬 B를 맞추려면 옥이, 두만, 서일몽 셋이 협력해야 함. 서일몽은 편지를 보이면 정체가 드러나는 위험을 진다

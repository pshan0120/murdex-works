# 백양둔의 밤 기획안 (가제, v0.3 초안)

작성 2026-11-10. 이 문서는 첫 초안이라 이름, 나이, 세부 사건은 모두 가칭과 가안이다.

---

## 1. 한 줄 컨셉

1930년 추석 밤, 간도의 국경 마을 백양둔. 개척민 대표가 주루 마방에서 죽은 채 발견되고, 그가 남긴 땅과 밀정 명부를 두고 열 사람이 거래하고 속이고 빼앗는다.

## 2. 출발점과 거리 두기 원칙

- 오프라인 작품 *Way out West*(Freeform Games)의 **진행 방식과 인물 구도**만 참고한다. 목표 중심 진행, 시간대별 사건, 아이템 거래, 중반의 땅 처분 결정이 그 범위다.
- 원작의 줄거리, 사건 경위, 아이템 구성, 서브플롯, 문장은 가져오지 않는다.
- 공개 판매가 목표라서, 인물 구도가 닮은 만큼 **사건의 진실과 핵심 장치는 원작과 확실히 다르게** 간다. 이번 초안에서는 진범, 사인, 두 번째 쟁탈 물건, 중간 이벤트를 모두 새로 짰다(9장 참고).
- 원작 번역 원고는 참고용으로만 두고, 이 폴더에는 복사하지 않는다.

## 3. 시대와 무대

### 3.1 시점
- 1930년 음력 8월 15일 밤. 만주사변 한 해 전이다.
- 간도는 중국 동북정권 관할이지만, 일본 영사관 경찰이 "조선인 보호"를 내세워 들어와 있다. 마을 하나에 법이 둘인 셈이다.
- 조선인 개척민이 만주 벌판을 논으로 바꿔 놓았지만, 조선인은 땅을 자기 이름으로 가질 수 없어서 중국인이나 귀화인 명의를 빌린 경우가 많았다. 이 사정이 땅 분쟁의 바탕이다.

### 3.2 무대
- **백양둔**: 두만강 건너 북쪽의 작은 마을. 개척 1세대가 수로를 파고 논을 일군 지 10년째.
- **금화루**: 마을에 하나뿐인 주루. 1층 주점과 마작방, 뒤편 마방, 2층 객실. 오늘 밤 추석 잔치가 여기서 열린다. 플레이는 모두 금화루 안에서 진행된다.
- 진행 안내는 금화루 점소이가 맡는다. 원작의 진행자처럼 즉석 판정은 하지 않고, 정해진 공지만 읽는다.

### 3.3 다룰 때 조심할 것
- 독립운동과 밀정을 다루므로, 독립운동가를 악역으로 쓰지 않고 일본 군경을 정의로운 법 집행자로 쓰지 않는다.
- 실존 사건은 배경으로만 언급하고, 실존 인물은 등장시키지 않는다.
- 학교, 회사, 단체 이름은 모두 가공한다.

## 4. 쟁탈 대상

### 4.1 개척단 논 (공론 투표 대상)
- 백양둔 앞 벌판의 논 서른 마지기. 명의는 귀화 조선인 이름을 빌렸고, 실제 권리는 죽은 한태수가 쓴 소작 계약서와 도장에 묶여 있다.
- 사려는 쪽이 둘이다.
  - **동아척식 출장원**: 사들여 일본인 감독 아래 집단 농장으로 만들 생각.
  - **용정 학원 재단**: 개척민 공동 소유로 남기고, 소출 일부로 학교를 운영할 생각.
- 여기에 **전당포 주인**이 "한태수가 빚 담보로 이 땅을 잡혔다"며 차용증을 내민다. 차용증의 도장은 진짜지만, 한태수가 직접 찍은 것은 아니다.
- 실제로 땅을 넘기려면 한태수의 도장이 있어야 한다. 도장 주머니는 시신에서 사라졌다(6장).
- 잔치 중반에 **마을 공론**을 열어 이 땅의 처분을 전원 투표로 정한다. 조선인민회장은 사회를 보고, 표가 같으면 결정권을 쓴다.
  - 선택지: 척식회사에 판다 / 학원 재단에 판다 / 진덕생의 차용증을 인정한다
  - 이해당사자도 한 표씩 가진다. 그래서 표를 사고, 협박하고, 설득하는 일이 중반의 중심 활동이 된다.

### 4.2 밀정 명부 (조합 대상)
- 한태수가 죽기 일주일 전 손에 넣은, 간도 조선인 사회에 숨은 영사관 밀정 명단.
- 한태수는 명부를 둘로 나눴다.
  - **쌀 장부처럼 보이는 숫자표** → 딸에게
  - **찬송가 책에 끼운 암호 열쇠** → 순경에게
- 두 가지를 한 사람이 모두 가지면 해독본이 열린다(머덱스 단서 의존 기능). 해독본에는 가명 넷이 적혀 있고, 그중 둘이 이 방 안에 있다.
- 원작의 "진짜·가짜 지도 반쪽" 구조는 쓰지 않는다. 가짜 명부는 없고, 해독본을 얻어도 가명이 누구인지는 다른 단서와 맞춰 봐야 알 수 있다.

## 6. 사건의 진실 (v0.3)

### 6.1 배경이 되는 과거

| 때 | 일 |
|---|---|
| 1920년 10월 | 일본군 토벌대가 간도의 조선인 마을들을 불태움. 회령에서 한약방을 하던 황보익이 돈을 받고 길을 안내함. 강두만의 아버지 강철수가 이때 죽음. 한태수 형제는 살아남음 |
| 1920년 겨울 | 강철수가 죽기 전 한태수 형제에게 마지막 편지를 보냄. "우리를 판 사람은 회령에서 약방을 하던 사람"이라는 말이 들어 있음. 이 편지는 지금 서일몽이 가지고 있음 |
| 1922년 | 황보익이 회령을 떠나 백양둔으로 옮겨 옴. 영사관은 그에게 가명 "학"을 붙여 밀정으로 계속 씀 |
| 1929년 11월 | 봉천의 마적 박만길이 죽음. 영사관 밀정 하나가 그의 이름을 쓰기 시작함(지금의 "칼자국") |

### 6.2 그날 하루

| 시각 | 일 |
|---|---|
| 일주일 전 | 한태수가 용정 쪽 동지에게서 밀정 명부를 받음. 명부의 "학"이 1922년에 회령에서 간도로 옮겼다는 기록을 보고, 강철수의 편지와 맞춰 황보익임을 알아챔 |
| 나흘 전 | 한태수가 용정 우체국에서 옥이 앞으로 편지를 부침. "내게 무슨 일이 생기면 강철수의 아들을 믿어라". 국경 열차 편이라 오늘 밤 단계 2에 도착함 |
| 사흘 전 밤 | 진덕생이 마작방에서 취한 한태수의 도장을 몰래 찍어, 날짜를 그날 밤으로 적은 차용증을 만듦. 류춘화의 숙박 장부에는 그날 밤 9시부터 한태수가 2층 객실에 혼자 있었던 기록이 있음. 차용증에는 "마작방에서 증인 앞에 날인"이라고 적혀 있음 |
| 같은 날 | 영사관이 명부가 새어 나간 것을 알아채고, 칼자국에게 회수를 맡김. 오카다는 이 일을 땅 매입 협박에 함께 쓰기로 함 |
| 오늘 오후 3시 | 한태수가 서일몽(동생)을 2층 상영실에서 만남. "오늘 밤 옛 빚을 정리한다"고만 말함 |
| 오후 4시 | 한태수가 명부를 둘로 나눠 딸과 강두만에게 맡김. 수란 할멈에게 "내게 무슨 일이 생기면 도장만은 나쁜 손에 넘어가지 않게 하라"고 말함 |
| 오후 4시 30분 | 칼자국이 술을 얻으러 금화루 주방에 들어감(서일몽은 3시 반에 물을 얻으러 들어갔음) |
| 오후 5시 | 한태수가 옥이에게 접은 쪽지를 주며 민회장에게 전하라고 함. 쪽지 내용은 "다섯 시 반, 마방에서. 태수". 옥이는 읽지 않고 전함 |
| 오후 5시 | 같은 때, 오카다와 칼자국이 마방으로 한태수를 찾아가 매도 서명과 명부를 요구함. 칼자국이 얼굴을 두 번 침. 한태수는 끝까지 거부함. 강두만이 둘이 마방에 들어가는 것을 봄 |
| 오후 5시 15분 | 오카다와 칼자국이 빈손으로 나와 2층 3호실(오카다의 객실)로 올라감. 류춘화가 3호실에 술 두 병을 올려 보냄. 강두만은 이 무렵 공안 분주소로 보고하러 감 |
| 오후 5시 20분 | 황보익이 잔치 음식을 둘러본다며 금화루 주방에 들어갔다가, 칼 한 자루를 두루마기 안에 감추고 나옴. 주방에서 쪽지를 아궁이에 넣었으나 끝이 다 타지 않음 |
| 오후 5시 30분 | 황보익이 마방에 들어감. 한태수는 "잔치가 시작되기 전에 마을을 떠나면 덮어 두겠다"고 말함. 황보익이 그를 찌르고, 품을 뒤져 명부를 찾다 못 찾고, 칼을 여물통 짚 속에 묻음 |
| 오후 5시 35분 | 진덕생이 마작방 판을 끝내고 일어섬(마작방 장부에 기록) |
| 오후 5시 40분 | 진덕생이 도장을 빼앗을 생각으로 마방에 다가갔다가, 문이 열리고 흰 두루마기에 갓을 쓴 사람이 나와 우물 쪽으로 가는 것을 봄. 안에 누가 있었다고 여기고 그냥 돌아감 |
| 오후 5시 45분 | 황보익이 우물에서 오른소매를 문질러 빨고 민회 사무소로 돌아감 |
| 오후 6시 | 수란 할멈이 마방에서 시신을 발견함. 몸은 식어 가고 있었음. 맥을 짚다 손바닥과 소매 끝에 피가 묻음. 허리춤의 도장 주머니를 챙겨 뛰쳐나옴. 분주소에서 돌아오던 강두만이 그 모습을 봄 |
| 오후 6시 | 같은 때, 류춘화가 3호실 빈 병을 거두러 올라감. 손님 둘이 방에 있었음 |
| 오후 6시 10분 | 칼자국이 혼자 마방에 다시 가서 명부를 찾음. 한태수가 이미 죽어 있었고, 짚 위의 피는 굳어 가고 있었음. 장화와 버선까지 벗겨 뒤졌으나 못 찾고 몸을 피함 |
| 오후 5시~6시 30분 | 서일몽과 윤기선은 2층 상영실에서 영사기를 맞춤 |
| 오후 6시 30분 | 류춘화가 잔치 상을 차리다 주방 칼 한 자루가 빈 것을 알아챔. 점심때는 있었음 |
| 오후 7시 | 잔치 시작. 서일몽이 잔치 기념사진을 찍음. 점소이가 시신 발견을 알림 |

### 6.3 인물별 오후 5시~6시 행적

| 인물 | 실제 행적 | 숨기려는 것 | 본 것 |
|---|---|---|---|
| 한옥이 | 5시 쪽지 심부름 후 말 손질 | 없음 | 쪽지를 민회장에게 전함 |
| 강두만 | 5시 마방 앞 감시, 5시 15분 분주소, 6시 복귀 | 감시를 비운 15분~6시 사이 | 오카다와 칼자국이 마방에 들어감, 6시 수란이 피 묻은 소매로 나옴 |
| 서일몽 | 상영실에서 윤기선과 영사기 맞춤 | 형제 관계 | 3시에 형이 한 말 |
| 진덕생 | 5시 35분까지 마작, 5시 40분 마방 앞 | 마방에 간 이유 | 두루마기에 갓 쓴 사람이 마방에서 나와 우물로 감 |
| 칼자국 | 5시 마방, 5시 15분~6시 3호실, 6시 10분 마방 | 두 번 다 마방에 갔다는 것 | 6시 10분 시신 상태 |
| 오카다 | 5시 마방, 5시 15분 이후 3호실 | 협박 | 마방을 나올 때 한태수는 살아 있었음 |
| 윤기선 | 상영실에서 서일몽과 영사기 맞춤 | 군자금 | 없음 |
| 황보익 | 주방, 마방, 우물, 민회 사무소 | 전부 | (진범) |
| 수란 할멈 | 6시 마방 | 도장 주머니 | 6시 시신 상태 |
| 류춘화 | 주방과 2층을 오감 | 장부를 진덕생에게 팔 생각 | 3호실 손님 둘, 오후에 주방에 들어온 손님 셋(서일몽, 칼자국, 민회장. 시각은 기억 못 함), 6시 반에 칼 한 자루가 빔, 아궁이의 타다 만 종이 |

### 6.4 의심받는 사람과 풀리는 길

| 의심받는 사람 | 의심받는 이유 | 풀리는 단서 조합 |
|---|---|---|
| 수란 할멈 | 피 묻은 소매, 도장 주머니 | 수란이 본 시신 상태(이미 식어 감) + 상처는 칼에 찔린 것이고 흉기는 주방 칼 + 류춘화가 기억하는 오후의 주방 손님 셋에 수란이 없음 |
| 칼자국 | 주먹질, 두 번 마방 출입, 시신을 뒤짐, 오후에 주방에 들어감 | 3호실 술 시중 기록(5시 15분~6시 손님 둘) + 숙박 장부의 3호실 투숙객 + 6시 10분에 피가 이미 굳어 감 |
| 오카다 | 협박, 매입 동기 | 칼자국과 같은 3호실 조합 |
| 류춘화 | 흉기가 자기 주방 칼 | 5시 15분과 6시에 2층을 오간 것은 3호실 손님 둘이 증언할 수 있음. 마방에서 나온 사람은 두루마기에 갓 차림 |
| 진덕생 | 5시 40분 마방 앞에 있었음, 땅 동기 | 마작방 장부(장소 조사 단서, 5시 35분 판 끝) + 그가 본 것은 이미 일이 끝난 뒤 나오는 사람 |
| 윤기선 | 기념사진에서 두루마기에 갓 차림 | 서일몽의 상영실 증언 |

### 6.5 진범을 가리키는 단서 사슬

두 갈래를 따로 두고, 어느 한쪽만으로는 확정되지 않게 한다.

**사슬 A: 그 시각 마방에 간 사람**
1. 옥이: 5시쯤 아버지 심부름으로 접은 쪽지를 민회장에게 전함
2. 주방 아궁이(장소 조사 단서): 타다 만 종이 조각 "…시 반, 마방에서"
3. 류춘화: 오후에 주방에 들어온 손님은 서일몽, 칼자국, 민회장. 6시 반에 칼 한 자루가 빔
4. 진덕생: 5시 40분 마방에서 흰 두루마기에 갓 쓴 사람이 나와 우물 쪽으로 감
5. 기념사진(서일몽, 단계 3에 인화): 그날 밤 두루마기에 갓 차림은 황보익과 윤기선 둘
6. 서일몽: 5시부터 6시 반까지 윤기선과 상영실에 있었음
7. 황보익 조사: 두루마기 오른소매 안쪽에 문질러 빤 갈색 얼룩

1과 2가 만나면 "쪽지를 받은 사람이 5시 반에 마방에 갔다"가 되고, 3은 흉기를 꺼낼 수 있었던 사람을 셋으로 좁힌다. 4·5·6이 만나면 "마방에서 나온 사람은 황보익"이 된다. 7은 보강이다.
- 칼자국은 3에 들어 있어 의심이 이어지지만, 6.4의 3호실 조합으로 빠진다.

**사슬 B: 왜 죽였나**
1. 해독된 명부: 가명 "학", 1920년 10월 토벌대 길 안내, 1922년 회령에서 간도로 거처를 옮김
2. 강철수의 마지막 편지(서일몽): "우리를 판 사람은 회령에서 약방을 하던 사람"
3. 금화루 소식지(공개): 민회장 황보익 소개 "회령에서 한약방을 하다 1922년 백양둔에 정착"

1과 2만으로는 "회령의 약방 주인"까지만 나오고, 3을 더해야 이름이 나온다.

**사슬 C: 칼자국의 정체(부가 질문용)**
1. 해독된 명부: 가명 "까마귀", 1929년 겨울부터 남의 이름을 씀
2. 현 공안국 공문(강두만, 단계 2): 마적 박만길은 1929년 11월 봉천에서 사망

**사슬 D: 차용증 위조(공론용)**
1. 진덕생의 차용증: 사흘 전 밤 "마작방에서 증인 앞에 날인"
2. 류춘화의 숙박 장부: 그날 밤 9시부터 한태수는 2층 객실에 혼자 있었음

D는 살인과 무관하지만 공론 결과를 뒤집을 수 있다. 류춘화가 장부를 진덕생에게 팔면 이 사슬은 끊긴다.

### 6.6 단서 문장 원칙

- 단서는 그 인물이 보고 들은 것까지만 쓴다. "민회장으로 보이는" 같은 추정이나 인물 이름 붙이기는 쓰지 않는다. 진덕생의 단서는 "흰 두루마기에 갓을 쓴 사람"까지만 적는다.
- 수식은 붙이지 않고 핵심 사실만 쓴다.
- 황보익에게는 단서 하나를 한 단계 동안 숨길 수 있는 능력(`HIDE_CLUE`, 1회)을 준다. 숨길 수 있는 대상은 자기 몸 조사 단서뿐이라, 사슬 A가 7 없이도 성립하도록 맞춘다.
- 역할지에 각자 그날 입은 옷을 적을 때, 두루마기에 갓 차림은 황보익과 윤기선만 되도록 맞춘다. 다른 인물의 옷차림 서술이 기념사진과 어긋나면 안 된다.

단서 문장 초안은 [단서_초안.md](단서_초안.md)에, 인물별 비밀과 능력은 [비밀_능력_초안.md](비밀_능력_초안.md)에 있다.

1. 한태수를 죽인 사람은? (투표)
2. 1920년 토벌대의 길잡이는? (투표)
3. "칼자국"은 어떤 사람인가? (투표, 객관식 넷)

## 7. 진행 단계 (가안)

| 단계 | 이름 | 내용 |
|---|---|---|
| 0 | 인물 읽기 | 역할지, 금화루 소식지, 규칙 안내 |
| 1 | 시신 발견 | 점소이 공지. 마방(시신, 여물통), 주방(아궁이), 마작방(장부) 조사 단서 공개. 탐색과 대화 |
| 2 | 국경 열차 도착 | 우편과 전보가 들어옴. 강두만에게 현 공안국 공문(박만길 사망), 오카다와 윤기선에게 본사 예산 전보, 옥이에게 한태수가 나흘 전 부친 편지. 전보는 미리 정해진 것만 쓴다 |
| 3 | 활동사진 상영 | 서일몽이 변사로 상영회를 진행하고, 상영실 암실에서 잔치 기념사진이 인화되어 나온다. **불이 꺼진 단계**라서 이 단계에서만 쓸 수 있는 빼앗기 행동이 있고, 누가 했는지 알림에 이름이 뜨지 않는다 |
| 4 | 마을 공론 | 전원 투표로 논의 처분을 정한다. 같은 단계에 황보익 전용 질문(동률일 때 고를 쪽)을 함께 둔다 |
| 5 | 자정 | 마적이 온다는 경보. 마지막 거래와 행동. 독, 압수 결과가 이 단계 끝에 확정된다 |
| 6 | 최종 질문 | 진범 지목과 부가 질문, 개인 엔딩 |

- 원작의 "중반 결정 전에는 아무도 죽지 않는다" 규칙은 머덱스에서 자연스럽게 성립한다. 죽음은 모두 엔딩 판정에서 정해지기 때문이다.

## 8. 머덱스 기능 대응

| 필요한 것 | 구현 방법 | 상태 |
|---|---|---|
| 능력 횟수 제한(게임 전체 N회) | role_action은 방마다 한 번만 쓰이므로 같은 능력을 N줄로 등록. 아이템 버튼은 트리거 `limit_count` | ✅ |
| 엿보기 능력(비밀 캐묻기 등) | role_action `PEEK_CLUE` | ✅ |
| 소매치기, 상영회 중 빼앗기 | `SEIZE_CLUE_RANDOM`·`SEIZE_CLUE_BLIND`, 상영 단계에서 `is_actor_identifiable=false` | ✅ 단계 한정 사용 가능 여부는 확인 필요 |
| 순경의 수색·압수 | `SEIZE_CLUE_REVEALED` | ✅ |
| 명부 해독 | 두 단서를 모두 가지면 해독본이 열리는 단서 의존 | ✅ 실제 동작 검증 필요 |
| 돈 | 대양 은화와 조선은행권을 몇 가지 액면 단서로 만들고 GIFT로 주고받음 | ✅ 액면 종류는 셋 이하로 |
| 독 | "약 탄 고량주" 단서를 건넴. 엔딩에서 그 단서를 갖고 해독 약초가 없으면 사망 | ✅ 엔딩 규칙 `neq` 조건 지원 확인함 |

| 결투, 기절, 응급처치 | 쓰지 않음 | 제외 |
| 진행자 즉석 판정 | 쓰지 않음. 가능한 행동을 미리 넉넉히 설계 | 제외 |

## 9. 원작과 달라진 점 점검

### 9.1 바꾼 것
- 시대, 장소, 민족 구성, 모든 이름
- 진범과 사인: 원작의 사건 경위와 다른 인물, 다른 방식
- 두 번째 쟁탈 물건: 밀정 명부. 진짜·가짜 구조 없음
- 땅 분쟁의 원인: 몰래 찍은 도장과 차용증
- 증거를 쥔 주루 주인의 물건: 숙박 장부
- 중간 이벤트: 활동사진 상영(불 꺼진 단계)이라는 새 장치
- 서브플롯: 치마, 매장지, 수배 포스터 등은 쓰지 않음
- 땅 처분 방식: 전원 투표 공론, 동률일 때만 사회자가 결정. 결정권이 다른 사람에게 넘어가는 장치는 없음
- 유모가 의심받는 계기: 피 묻은 소매와 사라진 도장 주머니. 흉기는 유모와 무관한 주방 칼
- 순경과 딸의 관계: 석 달 전 부임한 신참과의 앙숙. 순경 쪽 동기는 1920년에 죽은 아버지

### 9.2 닮은 채 남은 것
- 열 사람의 역할 구성(피해자의 딸, 순경, 정체를 숨긴 동생, 경쟁하는 두 매입자, 그 한쪽에 고용된 총잡이, 권위 있는 중재자, 유모, 주루 주인, 땅을 노리는 자)
- 중반에 땅 처분이 정해지는 흐름
- 유모가 현장에서 나오는 모습을 순경이 보는 출발점(계기와 물건은 바뀜)

### 9.3 판단
- 9.2에 남은 것은 인물 구도와 장르 관습 수준이라 그대로 간다.

## 10. 엔딩 방향

- 공통 엔딩은 진범 지목 결과와 땅의 결론으로 여섯 갈래.
- 개인 엔딩은 인물마다 2~5개, 모두 34편. 덧붙는 엔딩(누명, 독, 해독)이 따로 있다.
- 엔딩 규칙은 본인이 가진 단서만 볼 수 있어서, 남의 손에 있는 물건으로 갈리는 이야기는 그 물건을 가진 사람의 엔딩에만 쓴다.
- 조건과 내용은 [엔딩_설계.md](엔딩_설계.md)에 있다.

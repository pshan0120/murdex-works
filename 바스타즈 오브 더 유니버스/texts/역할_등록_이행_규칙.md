# 머덱스 역할 등록 정보 정리 이행 규칙 (SOP)

본 문서는 '바스타즈 오브 더 유니버스' 프로젝트의 캐릭터 정보를 플랫폼 등록용 규격으로 정리할 때 반드시 준수해야 하는 규칙을 정의합니다.

## 1. 기본 원칙 (Core Principles)
1. **데이터 무결성(Zero-Loss Fidelity)**: 원본 `역할_캐릭터_HTML.txt`의 모든 텍스트와 HTML 태그를 단 한 글자도 요약하거나 수정하지 않고 100% 그대로 유지합니다.
2. **요약 금지**: `...`, `(후략)`, `(중략)` 등의 표현은 절대 사용하지 않으며, 문장을 임의로 합치거나 삭제하지 않습니다.
3. **HTML 테마 유지**: 플랫폼의 디자인 시스템(예: `.highlight`, `.character-masters`, `<details>` 등)을 보존하기 위해 원본의 HTML 구조를 완벽하게 유지합니다.

## 2. 항목별 매핑 및 처리 규칙 (Mapping & Processing)

| 번호 | 항목명 | 처리 규칙 | 비고 |
| :--- | :--- | :--- | :--- |
| **1** | **역할 이름** | 원본 시트 상단의 직책(수장, 현자 등) 추출 | 텍스트만 |
| **2** | **캐릭터 이름** | 캐릭터 고유 명사 추출 | 텍스트만 |
| **3** | **역할 순서** | `기본정보.txt`에 정의된 공식 순서(1~7) 적용 | 숫자만 |
| **4** | **역할 요약** | 원본 '역할 요약' 섹션에서 **HTML 태그를 제거**한 순수 텍스트 | 텍스트만 |
| **5** | **역할 이미지** | "사용자 직접 업로드 예정" 문구로 대체 | 무시 |
| **6** | **공개 정보** | 원본 도입부의 연합원 공유용 `<ul>` 리스트 포함 HTML | HTML 포함 |
| **7** | **역할 시트** | **[상세 설명 / 타임라인 / 특징 / 인물 관계]** 전체를 하나의 HTML 블록으로 통합 | 원본 100% 복사 |
| **8** | **비밀** | '비밀' 섹션의 전체 내용 포함 HTML | HTML 포함 |
| **9** | **목표** | [조사 1단계]와 [추리 1단계 이후]로 각각 섹션을 나누어 HTML 구성 | **단계별 분리** |
| **10** | **단계별 역할 지침** | [조사 1단계]와 [추리 1단계 이후]로 각각 섹션을 나누어 HTML 구성 | **단계별 분리** |

## 3. 세부 작업 지침 (Detailed Instructions)

### A. 역할 시트 통합 (Item 7)
- 원본의 `상세 설명`, `타임라인`, `특징`, `인물 간 관계 및 말투` 섹션을 순서대로 이어 붙입니다.
- 각 섹션이 플랫폼 내에서 접고 펼칠 수 있도록 `<details>` 혹은 `<div class="story-content">` 구조를 유지합니다.

### B. 단계별 분리 (Items 9 & 10)
- 원본에서 하나의 블록 안에 작성된 '목표'와 '플레이 팁'을 각각의 단계(`17시~18시` / `18시 이후`)로 물리적으로 분리합니다.
- 분리된 각 파트는 독립적으로 동작하는 **완전한 HTML 스니펫**이어야 합니다.

### C. 자가 검증 (Verification)
- 작업 완료 후, 생성된 파일의 텍스트 양이 원본 파일의 텍스트 양과 근사한지 확인합니다.
- 반드시 모든 캐릭터의 **원본 순서**를 상호 대조하여 '역할 순서' 필드를 정확히 기재합니다.

■ 목적
텀블벅_펀딩_기획.txt에 이미 확정된 "기밀 수사 파일(Case File)" 컨셉을 실제로 Canva에서 제작할 때 참고할 실행 가이드. AI 이미지 생성이 필요한 것과, Canva 소재로 바로 가져다 쓰는 게 나은 것을 구분해서 정리함.

- PAGE 2 컨셉 훅: 코르크보드 배경 - 신규 생성 1장 (아래 프롬프트)
- PAGE 3 STORY: 컷씬(안개 낀 클레이 연구소) - images/cutscenes/ 재사용
- PAGE 4 진행 방식: 실제 화면 스크린샷 - AI 생성 아님, 사용자가 직접 캡처
- PAGE 5 CAST: 베일라/마커스 프로필 - images/roles/ 재사용, 인사기록카드 프레임만 Canva로 추가

※ 삭제된 FEATURES 페이지의 "증거 사진" 2장 프롬프트(아래 [PAGE 4-A]/[PAGE 4-B])는 이미 생성했다면 STORY나 INFO 페이지의 장식용 인서트로 재활용 가능. 아직 안 만들었다면 신규 생성 불필요.

■ 페이지 캔버스 비율 (2026-09-08 확인, 같은 날 전체 2:3 통일로 갱신)
텀블벅 "프로젝트 계획" 탭의 페이지 하나하나는 가로 인서트가 아니라, 바스타즈 때처럼 세로로 길게 이어지는 포스터형 캔버스임(배경 일러스트 위에 제목·카피가 위에서 아래로 쌓이는 구조). 처음엔 PAGE 4의 "증거 사진" 인서트는 페이지 배경이 아니니 가로 구도를 유지해도 된다고 봤으나, 작업 편의를 위해 신규 생성 이미지 전부(PAGE 1/2/4 A·B) 세로 2:3 비율로 통일함. 4번 증거 사진 2장은 좌우 배치였던 오브제 구도를 상하 배치로 바꿔서 세로 프레임에 맞춤.

■ 디자인 가이드 (Canva 작업용)

1. 색 팔레트 - 두 레이어로 구분해서 생각할 것 (2026-09-08 수정: 골드 계열 배제, 청록/레드/회색 3톤으로 확정)
- 사진 레이어(AI 생성 이미지 자체): 기존에 확립된 "채도 낮은 녹회색-청록" 톤 그대로 유지. 손대지 말 것.
- 그래픽/UI 레이어(Canva에서 얹는 도장·텍스트·선, 페이지 타이틀 포함): 레드 한 가지만 포인트로 사용(도장, 레드액션 바, 강조 텍스트·숫자). 골드/브론즈 계열은 쓰지 않음 - 판타지·서사시 톤이라 도플로이드의 SF 느와르 분위기와 맞지 않음. 서류·라벨 배경 및 보조 텍스트용으로는 크림색 대신 회색 계열(예: 밝은 회색 #C7CBC8, 어두운 회색 #4A4F4E) 사용. 그 외 색은 늘리지 말 것 - 사진 톤(청록) + 레드 + 회색, 딱 3톤 유지.

2. 폰트 - 두 가지만 사용
- 타자기체: "서류/도장/케이스 넘버"처럼 보여야 하는 모든 텍스트에. Canva 검색: Special Elite / Courier Prime / Xanh Mono 중 하나로 통일.
- 본문 고딕체: 일반 설명 문단(카피 본문)엔 깔끔한 산세리프 하나만. 두 폰트가 페이지마다 다르게 섞이지 않도록 7페이지 전부 동일하게 고정.

3. 반복 그래픽 키트 - AI로 만들지 말고 Canva 소재 검색으로 찾을 것
사진(오브제)은 AI가 잘 만들지만, 도장·클립·보드 같은 그래픽 요소는 Canva 라이브러리에 이미 이 컨셉에 맞는 무료 소재가 많아 그쪽이 더 빠르고 깨끗함. Canva 소재 검색창에 검색:
- classified stamp / top secret stamp - 빨간 원형/사각 도장, 살짝 회전시켜서 붙이기
- paperclip - 사진 모서리에 걸쳐 붙이기
- redacted / redaction bar - 7번 페이지(INFO) 체크리스트에 한두 군데만 포인트로
- case file folder / manila folder - 배경 프레임용
- polaroid frame / id photo border - 5번 CAST 페이지 인물사진 테두리용

4. 레이아웃 통일 규칙
- 모든 페이지 같은 모서리(예: 우측 상단)에 "CASE NO. / FILED:" 도장 블록을 고정 배치 - 페이지가 넘어가도 같은 파일철 느낌이 나도록.
- 사진에는 항상 얇은 흰 테두리(폴라로이드처럼 3~5mm)를 둘러서 실물 인화 사진을 붙여놓은 느낌 유지.
- 도장은 매번 살짝 다른 각도로 회전(-8도~8도 사이)해서 손으로 찍은 것처럼 - 전부 수평으로 나란하면 오히려 어색해 보임.
- 텍스트 박스 배경은 종이색 사각형 + 아주 옅은 그림자(서류가 살짝 떠 있는 듯한 느낌)로 통일.

■ PAGE 1 HERO / PAGE 7 GAME INFO 구성 확정 (2026-09-08, 2026-09-11 수정)
- HERO(PAGE 1)는 훅만 남기고 스펙 정보는 최소화: 타이틀(THE S-FILES: DOPLOID) + "MURDER MYSTERY FOR 2 PLAYERS" 한 줄만 유지. 원래 있던 세계관 설명 문단(전쟁/반역자 승리)은 삭제 - 그 내용은 PAGE 3 STORY에서 풀 내용이라 커버에서 미리 다 보여줄 필요 없음. "2인용"만 커버에 남기는 이유는 스펙이 아니라 차별점이기 때문 - 머덱스의 다른 작품 대부분이 3인 이상이라 도플로이드의 2인용은 그 자체로 훅이 됨.
- 나머지 스펙 4개(플레이 시간/분기 엔딩/장르 등)는 PAGE 7 GAME INFO로 이동. 바스타즈 사례(정보 리스트 → 타이틀 반복으로 마무리)와 동일한 구조를 따르되, 스타일은 바스타즈의 흰 고딕체+골드 타이틀이 아니라 도플로이드 문법(라벨:값 쌍을 타자기체로, 배경은 사진 없이 순수 다크 배경)으로 재구성. 예: "PLAYERS: 2 / RUNTIME: 60–80 MIN / ENDINGS: MULTIPLE / GENRE: SF THRILLER" 나열 후 하단에 타이틀 반복 배치.
- HERO 하단 강조 텍스트("2 PLAYERS"의 "2" 등 숫자·핵심어 강조)는 위 색 팔레트 규칙에 따라 골드가 아닌 레드로 통일.
- (2026-09-11 수정, 테스터 피드백) 태그라인 "낯설고도 낯익은 얼굴"은 HERO에서 삭제. 폰트가 타이틀과 안 어울린다는 지적이 있었고, 같은 문구가 PAGE 2 BRIEFING 첫 줄과 프로젝트 요약에 이미 있어 중복이기도 했음. 대신 새로 뺄 폰트를 찾기보다 아예 빼서 타이틀 + 하단 한 줄만 남기는 쪽으로 정리 - HERO를 더 미니멀하게 유지하는 기존 방향과도 맞음.

■ PAGE 5 CAST 구성 수정 (2026-09-11, 테스터 피드백)
- 캐릭터 소개 캡션이 사진 속 얼굴을 가리지 않도록 배치 - 하단 여백이나 사진 옆 별도 라벨 영역에 텍스트를 두고, 얼굴이 있는 중앙~상단부는 비워둘 것.
- 카피에서 "~한 분에게 잘 맞습니다" 식 취향 추천 문장 삭제. 이름/역할까지만 남기고, 마지막의 "감정을 따라갈 것인가, 근거를 따질 것인가" 대비 카피로 마무리 - 캐릭터의 서사보다 게임 컨셉(대비 구조)을 보고 구매를 결정한다는 판단.
- (2026-09-11 2차 수정) 한 줄 소개 문구도 다시 씀 - 기존 "잃어버린 과거의 퍼즐을 쫓는"(베일라), "개인적인 사연과 원칙 사이에서 흔들리는"(마커스)은 역할 시트의 내부용 "역할 요약" 문구를 그대로 썼던 것인데, 둘 다 각자가 개인적인 비밀을 품고 있다는 걸 너무 직접적으로 암시해 스포일러에 가까웠음. 실제 조사 방식(베일라: 단서를 놓치지 않고 끈질기게 파고드는 탐정형 / 마커스: 원칙과 증거로 사건을 정리하는 수사형)만 드러내는 문구로 교체. 나이도 제거.

■ 참고 - 텀블벅 실제 상위 프로젝트 구조 조사 (2026-09-08)
"머더미스터리" 검색 상위 프로젝트(딜라이트/커넥트 게임즈/7pmGames 등)를 직접 열어봤으나, 이 환경에서는 텀블벅 이미지 서버(img.tumblbug.com) 접근이 네트워크 차단되어 실제 소개 이미지는 볼 수 없었음(스크린샷 백지, fetch 실패로 확인). 대신 확인 가능했던 구조: 히어로 영역에 영상 재생 버튼이 있는 박스아트형 이미지, 모금 현황 바로 아래 최근 후원자 리뷰가 크게 노출되는 신뢰 장치, 소개/선물설명/예산/일정/팀소개/신뢰와안전 탭 구조. 도플로이드 기획안(텀블벅_펀딩_기획.txt)의 7페이지 구조·탭 구성은 이 관례와 이미 부합함.

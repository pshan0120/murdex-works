[작험 기본 정보 설정 가이드]

이 문서는 <머덱스> 에디터의 '기본 정보 설정' 탭을 작성할 때 참고하는 가이드입니다. 
각 항목의 의미와 입력 예시를 확인하여 작품을 완성해 보세요.

------------------------------------------------------------
1. 제목 (Title)
------------------------------------------------------------
- 설명: 작품의 얼굴입니다. 플레이어의 시선을 끌 수 있는 매력적인 제목을 정해 주세요.
- 입력 내용: 심야의 편의점

------------------------------------------------------------
2. 카테고리 (Category)
------------------------------------------------------------
- 설명: 작품의 장르를 선택합니다. (에디터 내 드롭다운에서 선택)
- 입력 내용: 클래식 미스터리 (CLASSIC)

------------------------------------------------------------
3. 요약 (Summary)
------------------------------------------------------------
- 설명: 작품 리스트에서 보여질 짧은 소개글입니다. 핵심 사건이나 분위기를 한 줄로 요약하세요.
- 입력 내용: 비 내리는 밤, 고립된 편의점에서의 살인 사건. 용의자는 단 4명, 60분 안에 진범을 찾아라!

------------------------------------------------------------
4. 가격 (Price)
------------------------------------------------------------
- 설명: 플레이어가 작품을 구매할 때 지불하는 금액입니다. (숫자만 입력)
- 입력 내용: 0 (무료 작품인 경우)

------------------------------------------------------------
5. 플레이 시간 (Duration)
------------------------------------------------------------
- 설명: 예상되는 전체 게임 진행 시간(분)을 입력합니다. (숫자만 입력)
- 입력 내용: 60

------------------------------------------------------------
6. 인원 설정 (Players)
------------------------------------------------------------
- 최소 인원: 게임 진행에 필요한 가장 적은 플레이어 수 (예: 2)
- 최대 인원: 게임에 참여할 수 있는 가장 많은 플레이어 수 (예: 2)
- 참고: 튜토리얼 시나리오는 1:1 대결 구도이므로 최소/최대 인원을 동일하게 설정했습니다.

------------------------------------------------------------
7. 난이도 (Difficulty)
------------------------------------------------------------
- 설명: 추리에 필요한 논리력이나 정보의 양을 고려하여 선택합니다.
- 입력 내용: 쉬움 (EASY)

------------------------------------------------------------
8. 권장 연령 (Target Age)
------------------------------------------------------------
- 설명: 작품의 수위나 난이도를 고려하여 적절한 권장 연령을 적어주세요.
- 입력 내용: 15세 이용가 (또는 전체 연령 등)

------------------------------------------------------------
9. 색상 설정 (Theme Colors)
------------------------------------------------------------
- 설명: 게임 화면의 기본 톤을 설정합니다. (헥사 코드 입력 가능)
- 텍스트 색상: #FFFFFF (흰색)
- 배경 색상: #000000 (검정색)

------------------------------------------------------------
10. 대표 이미지 URL (Cover Image)
------------------------------------------------------------
- 설명: 작품을 대표하는 메인 포스터 이미지의 URL입니다. (직접 업로드하거나 URL 입력)
- 가이드: 16:9 또는 4:3 비율의 고화질 이미지를 권장합니다.
- 예시: https://example.com/cover-image.jpg

------------------------------------------------------------
11. 태그 설정 (Tags)
------------------------------------------------------------
- 설명: 작품의 특징을 나타내는 키워드입니다. 검색 및 추천에 활용됩니다.
- 입력 내용: #미스테리 #추리 #초보자추천 #밀실

------------------------------------------------------------
12. 커스텀 테마 CSS (Custom CSS)
------------------------------------------------------------
- 설명: 게임 화면의 디자인을 더 세밀하게 조정하고 싶을 때 사용합니다. CSS 지식이 필요합니다.
- 입력 내용:
/* 기본 폰트 및 배경 설정 예시 */
.game-content-area {
  font-family: 'Pretendard', sans-serif;
  line-height: 1.6;
}

------------------------------------------------------------
13. 상세 설명 (Description)
------------------------------------------------------------
- 설명: 작품 입장 전 플레이어가 보게 되는 상세 배경 스토리입니다. (에디터의 리치 텍스트 도구 사용 가능)
- 입력 내용:
<p class="ql-align-center"><strong style="font-size: 18px;">"범인은 이 안에 있어. 아무도 나갈 수 없다."</strong></p><p><br></p><p>202X년 7월 15일, 장마철의 새벽 1시.</p><p>폭우가 쏟아져 세상이 물에 잠긴 듯한 밤입니다. 손님이 뚝 끊긴 '24시 행복마트'에서 둔탁한 소리가 들려옵니다.</p><p><br></p><p>야간 아르바이트생 <strong>'김알바'</strong>와 늦은 저녁을 해결하러 온 단골 손님 <strong>'이고시'</strong>.</p><p>그리고 비를 피해 들어온 배달 기사와 취객 한 명.</p><p><br></p><p>조금 전까지 카운터에 있던 점장 '나점장(45세)'이 창고 바닥에서 싸늘한 주검으로 발견됩니다.</p><p>머리에는 둔기에 맞은 흔적이 있고, 카운터의 금고는 텅 비어 있습니다.</p><p>폭우로 인해 도로가 끊겨 경찰의 도착까지는 1시간이 걸린다고 합니다.</p><p><br></p><p>그전까지 범인을 찾아내야 합니다. <strong>범인은 분명 이 편의점 안에 있습니다.</strong></p>

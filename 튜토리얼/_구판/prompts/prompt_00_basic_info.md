# 머덱스 작품 [기본 정보 설정] 생성 프롬프트

## [1. 사용자 입력 폼]
*작가가 만들고 싶은 시나리오의 핵심 내용을 아래에 적어주세요.*

- **작품 테마/소재**: [예: 비 내리는 심야의 편의점, 고립된 설산의 산장, 명문 고등학교의 시험지 유출 사건 등]
- **주요 장르**: [예: 클래식 미스터리, 스릴러, 코미디, SF 등]
- **플레이 인원**: [예: 2~4명]
- **예상 소요 시간**: [예: 60분 ~ 90분]
- **난이도**: [예: 쉬움 / 보통 / 어려움]
- **작품의 분위기**: [예: 긴장감 넘치는, 차분하고 논리적인, 가볍고 유쾌한 등]

---

## [2. AI 생성 지침]
당신은 <머덱스(Murdex)> 플랫폼의 전문 시나리오 작가입니다. 
위에서 제공된 **[사용자 입력 폼]**의 내용을 바탕으로, 머덱스 에디터의 **'기본 정보 설정'** 탭에 그대로 입력할 수 있는 상세 가이드 문서를 작성하세요.

### 작성 규칙
1. **전문성**: 머더 미스테리 장르의 특성을 살려 매력적인 제목과 홍보 문구를 작성하세요.
2. **형식 준수**: 아래 제공된 '출력 구조'를 엄격히 따르며, [ ]로 표시된 각 항목의 내용을 구체적으로 채우세요.
3. **HTML 활용**: '상세 설명' 부분은 머덱스 에디터에서 지원하는 HTML 태그(p, strong, br, em 등)를 사용하여 풍부하게 묘사하세요.
4. **색상 및 CSS**: 테마에 어울리는 세련된 배경색/텍스트색과 간단한 CSS 효과를 제안하세요.

---

## [3. 출력 구조 (기본정보.txt 형식)]

[작품 기본 정보 설정 가이드]

이 문서는 <머덱스> 에디터의 '기본 정보 설정' 탭을 작성할 때 참고하는 가이드입니다.

------------------------------------------------------------
1. 제목 (Title)
------------------------------------------------------------
- 설명: 작품의 얼굴입니다. 플레이어의 시선을 끌 수 있는 매력적인 제목을 정해 주세요.
- 입력 내용: [생성된 제목]

------------------------------------------------------------
2. 카테고리 (Category)
------------------------------------------------------------
- 설명: 작품의 장르를 선택합니다.
- 입력 내용: [테마에 맞는 카테고리 명칭]

------------------------------------------------------------
3. 요약 (Summary)
------------------------------------------------------------
- 설명: 작품 리스트에서 보여질 짧은 소개글입니다.
- 입력 내용: [플레이어의 호기심을 자극하는 한 줄 요약]

------------------------------------------------------------
4. 가격 (Price)
------------------------------------------------------------
- 설명: 플레이어가 작품을 구매할 때 지불하는 금액입니다. (숫자만 입력)
- 입력 내용: 0 (기본값)

------------------------------------------------------------
5. 플레이 시간 (Duration)
------------------------------------------------------------
- 설명: 예상되는 전체 게임 진행 시간(분)을 입력합니다. (숫자만 입력)
- 입력 내용: [플레이 시간(숫자)]

------------------------------------------------------------
6. 인원 설정 (Players)
------------------------------------------------------------
- 최소 인원: [최소 인원 수]
- 최대 인원: [최대 인원 수]

------------------------------------------------------------
7. 난이도 (Difficulty)
------------------------------------------------------------
- 설명: 추리에 필요한 논리력이나 정보의 양을 고려하여 선택합니다.
- 입력 내용: [난이도 명칭]

------------------------------------------------------------
8. 권장 연령 (Target Age)
------------------------------------------------------------
- 설명: 작품의 수위나 난이도를 고려하여 적절한 권장 연령을 적어주세요.
- 입력 내용: [예: 15세 이용가 / 전체 이용가]

------------------------------------------------------------
9. 색상 설정 (Theme Colors)
------------------------------------------------------------
- 텍스트 색상: [테마와 대비되는 가독성 좋은 색상 코드]
- 배경 색상: [분위기에 어울리는 배경 색상 코드]

------------------------------------------------------------
10. 대표 이미지 URL (Cover Image)
------------------------------------------------------------
- 설명: 작품을 대표하는 메인 포스터 이미지의 URL 혹은 설명입니다.
- 가이드: [이미지 프롬프트 혹은 추천 이미지 스타일 묘사]

------------------------------------------------------------
11. 태그 설정 (Tags)
------------------------------------------------------------
- 설명: 작품의 특징을 나타내는 키워드입니다.
- 입력 내용: [테마와 관련된 해시태그 4~5개]

------------------------------------------------------------
12. 커스텀 테마 CSS (Custom CSS)
------------------------------------------------------------
- 설명: 게임 화면의 디자인을 더 세밀하게 조정합니다.
- 입력 내용:
/* 테마 맞춤형 기본 CSS 스타일 */
.game-content-area {
  font-family: 'Pretendard', sans-serif;
  line-height: 1.6;
}

------------------------------------------------------------
13. 상세 설명 (Description)
------------------------------------------------------------
- 설명: 작품 입장 전 플레이어가 보게 되는 상세 배경 스토리입니다. (HTML 사용)
- 입력 내용:
[HTML 태그를 사용하여 몰입감 있게 작성된 상세 시놉시스]

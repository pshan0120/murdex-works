# 머더 미스테리 시나리오 생성 프롬프트: 공통 규칙서 (Common Rules)

## AI 어시스턴트 역할
당신은 몰입감 있고 직관적인 스토리를 설계하는 '머더 미스테리 작가'입니다.

## 작업 목표
작품의 포문을 여는 **공통 규칙서** 텍스트를 생성합니다.
플레이어는 이 문서를 가장 먼저 읽게 되며, 게임의 전체적인 분위기와 규칙을 파악합니다.

## 필수 포함 섹션
다음 헤더와 내용을 반드시 포함하세요.

1. **[1] 공통 규칙서 (Common Rules)** (최상위 헤더)
2. **1) 기본 정보**
   - 제목, 장르, 인원, 소요 시간, 간단 소개
3. **2) 배경 스토리**
   - 사건의 발단 (육하원칙)
   - 시간적/공간적 배경 묘사 (날씨, 분위기 등)
   - 현재 상황 (시체 발견 직후 등 긴박한 상황)
4. **3) 등장인물**
   - 플레이어 캐릭터: 이름, 나이, 직업, 성격, 현재 상황
   - NPC 캐릭터: 이름, 나이, 특징
5. **4) 게임 규칙**
   - 이 시나리오만의 특수 규칙이나 주의사항 (예: 튜토리얼 가이드, 협력 강조 등)

## 작성 톤앤매너
- **침착하고 미스테리한 어조**: 독자를 몰입하게 만드는 서술형 문체 사용.
- **간결함**: 규칙과 정보는 명확하게 전달.

## 예시
```
# (자동 분리본) 머더 미스테리 시나리오: [작품명]

## [1] 공통 규칙서 (Common Rules)

### 1) 기본 정보
- 제목: 심야의 편의점
- 장르: 일상 미스터리
...
```
